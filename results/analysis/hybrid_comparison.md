## Reading the numbers

- UNKNOWN counts as incorrect for accuracy. It is neither a confirmed bug nor an explicit SAFE claim.
- A working input means an UNSAFE claim marked `confirmed` on a gold UNSAFE case. This uses the existing harness status; it does not strengthen or re-check that harness.
- SAFE remains the selected method's claim. Requiring replay for bug claims does not prove SAFE answers.
- Calls and tokens describe the responses needed by the policy. Hybrid totals include every recorded Z3 repair call, plus CoT only when selected. They are estimates, not a bill for fresh API calls.
- Cached component times cannot establish hybrid runtime; no hybrid runtime is reported.
- The CSV also includes accuracy, coverage, precision, confirmed-bug recall, false SAFE claims and UNKNOWN answers on buggy cases. Precision is N/A when there are no UNSAFE claims.
- These comparisons are exploratory and are excluded from the existing Holm-corrected test family. A small observed gain does not establish general superiority.
