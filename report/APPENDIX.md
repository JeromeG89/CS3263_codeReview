### T1-BND-01

**T1 flat · array bounds · precondition twin** — tags: off_by_one

- **UNSAFE version:** Reads the element after i; i may be the last index.
- **Bug:** With i == n-1 the access buf[i+1] reads buf[n].
- **SAFE version:** Same code; precondition guarantees i+1 < n.

#### T1-BND-01-U — UNSAFE

What the model saw:

```c
/* Function under review: next_item
 * Preconditions (guaranteed by every caller of next_item):
 *   1 <= n && n <= 64
 *   0 <= i && i < n
 *   buf points to an array of exactly n elements of type int
 */
int next_item(const int *buf, int n, int i) {
    return buf[i + 1];
}
```

Preconditions (machine form):

- `1 <= n && n <= 64`
- `0 <= i && i < n`
- length of `buf` = `n`

Witness: `{"buf": [7], "n": 1, "i": 0}`

Reference Z3 encoding (unwind bound for CBMC: 40):

```python
from z3 import *
buf = Array('buf', BitVecSort(32), BitVecSort(32))
n, i = BitVecs('n i', 32)
s = Solver()
s.add(1 <= n, n <= 64, 0 <= i, i < n)
idx = i + 1
s.add(Or(Not(BVAddNoOverflow(i, BitVecVal(1, 32), True)), idx < 0, idx >= n))
```

Validation: witness triggers `bounds`; reference Z3 → UNSAFE; CBMC → UNSAFE — **all checks pass**.
